## Plan

Blocker resolved via ADR-0002 (`IKnockbackable` + `Mover.IsOverridden`, already implemented in code by architect-role). Remaining coder-side work:

1. Add `AuraAreaDetector.FindTargetsInRadius(Vector3 center)` overload (additive; existing `FindTargetsInRadius(ExecutorData)` unchanged) so an effect can resolve the area at an arbitrary point instead of only the caster's position.
2. Add `KnockbackAreaEffect.cs` (`Assets/Scripts/Gameplay/Skill System/`), `MonoBehaviour, ISkillEffect`:
   - `[SerializeField] AuraAreaDetector _detector`, `_maxRangeFromCaster`, `_knockbackSpeedPerSecond`, `_knockbackDurationInSeconds`.
   - `Run(ExecutorData)`: resolve mouse world point (`Camera.main.ScreenToWorldPoint(Input.mousePosition)`), clamp offset from `executorData.Position` to `_maxRangeFromCaster` via `Vector2.ClampMagnitude`, call the new detector overload at the resolved point, then for each target `is IKnockbackable` call `ApplyKnockback(direction away from resolved point, speedPerSecond, durationInSeconds)`. Applied once per execution (instant yield), matching the one-shot style of `NearestVampireDamageEffect`.
3. Verify: `dotnet build` green; `git status` shows only the two new/changed files (plus their `.meta`s, which Unity generates on next editor open — not created by this session).
